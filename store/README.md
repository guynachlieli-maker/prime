# חנות "שלווה": הוראות הפעלה

אתר מכירה של מוצר אחד, בעברית ומימין לשמאל. הקנייה והסליקה מתבצעות בקופה של Shopify.

- `index.html`: דף המוצר הממיר
- `policies.html`: משלוחים, החזרות, תקנון, פרטיות, הצהרת נגישות (ממלאים את הקטעים הצהובים)
- `config.js`: **הקובץ היחיד שצריך לערוך**: מחירים, חיבור Shopify, פרטי קשר, פיקסלים, ביקורות
- `MARKET_RESEARCH.md`: סקר השוק ונימוקי הבחירה
- `assets/`: תמונות המוצר

## 1. המוצר בשופיפיי

ב-Shopify Admin > Products > Add product:
- כותרת: `שלווה: מכשיר עיסוי שיאצו לצוואר ולכתפיים עם חימום`
- אפשרות (Option) בשם `חבילה` עם 3 ערכים, וכל ערך בווריאנט עם מחיר משלו:
  | ווריאנט | מחיר | Compare-at |
  | --- | --- | --- |
  | מכשיר אחד | 249 | 399 |
  | זוג | 429 | 798 |
  | שלישייה | 579 | 1197 |
- סטטוס Active, וזמין בערוץ המכירה **Headless** (או Shopify Buy Button).

מזהה כל ווריאנט: פותחים את הווריאנט ב-Admin, והמספר בסוף הכתובת הוא ה-ID. ב-`config.js` כותבים `gid://shopify/ProductVariant/<המספר>`.

## 2. מפתח Storefront

Shopify Admin > Sales channels > מתקינים את **Headless** > Create storefront > מעתיקים את **Public access token**.
ב-`config.js` ממלאים את `shopify.domain` (למשל `shalva-il.myshopify.com`) ואת `shopify.storefrontToken`. זה מפתח ציבורי שמיועד לדפדפן, אז מותר לשים אותו באתר.

## 3. סליקת אשראי

הסליקה עצמה מוגדרת בשופיפיי, לא באתר: **Settings > Payments**.
Shopify Payments לא זמין לעסקים בישראל, ולכן מחברים ספק סליקה ישראלי שמשתלב ב-Shopify (למשל PayPlus, Grow/משולם, CardCom, Tranzila או Hyp). בודקים אצל הספק: תשלומים, Bit, Apple Pay ו-Google Pay. לחשבונות שאינם ישראליים: Shopify Payments או PayPal.
בנוסף: **Settings > Languages**: מוסיפים עברית ומפרסמים אותה, כדי שהקופה תוצג בעברית. **Settings > Checkout**: מבקשים מספר טלפון כדי שיהיה למי לשלוח עדכוני משלוח.

## 4. תמונות

שמים בתיקייה `assets/` את `product-1.jpg` (ריבועית, 1200x1200 לפחות). עד שתהיה תמונה, מוצגת הדמיה מצוירת. המלצה: לצלם את המוצר האמיתי על אדם, על רקע בהיר.

**לוודא מול הספק** שהמפרט באתר נכון (8 ראשי עיסוי, 3 עוצמות, כיבוי אחרי 15 דקות, מתאם לרכב, תקע ישראלי, אחריות 12 חודשים), ולתקן ב-`index.html` אם צריך.

## 5. העלאה לאוויר

זה אתר סטטי: מעלים את כל התיקייה `store/` ל-Netlify, Vercel, Cloudflare Pages או GitHub Pages, ומחברים דומיין. בדיקה מקומית:
```bash
cd store && python3 -m http.server 8080
```
